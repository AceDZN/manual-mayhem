## שאלות ותשובות

### מה משפט תנאי מוסר לקורא?

משפט תנאי בנוי משני חלקים: פסוקית שנפתחת ב-if ומציגה תנאי, ופסוקית תוצאה שמספרת מה קורה כשהתנאי מתקיים. בכיתה ט פוגשים שני דגמים, והם נבדלים במה שהם מוסרים ולא רק בצורתם. If you heat water to one hundred degrees, it boils. אם מחממים מים למאה מעלות, הם רותחים. זהו דבר שקורה תמיד, בכל פעם מחדש. If it rains tomorrow, we will move the game indoors. אם ירד גשם מחר, נעביר את המשחק פנימה. זהו מקרה אחד, אפשרי אך לא ודאי. ההבדל אינו בפסוקית ה-if, שנראית כמעט זהה בשניהם, אלא בפסוקית התוצאה: it boils מוסר חוק קבוע, ואילו we will move מוסר תחזית למקרה מסוים.

### למה אין will אחרי if גם כשמדובר במחר?

כי באנגלית פסוקית שנפתחת ב-if לוקחת הווה פשוט, גם כשהמשמעות שלה היא עתיד. העתיד כבר מסומן פעם אחת במשפט, ב-will של פסוקית התוצאה, ואין צורך לסמן אותו פעמיים. לכן If it rains tomorrow, we will move the game indoors. אם ירד גשם מחר, נעביר את המשחק פנימה. בעברית ״ירד״ הוא עתיד, ולכן התרגום המילולי מפתה מאוד, אבל הוא אינו אנגלית תקינה. אותו כלל חל גם אחרי when, before ו-after: When the film ends, we will call you.

### מה ההבדל בין If you heat water, it boils לבין If you heat the water, it will boil?

ההבדל הוא במה שהמשפט מוסר, ולא בנכונות שלו. הראשון הוא zero conditional ומוסר חוק: מים רותחים בכל פעם שמחממים אותם מספיק, תמיד ובכל מקום. אם מחממים מים, הם רותחים. השני הוא first conditional ומוסר תחזית למקרה אחד, לסיר הזה ועכשיו. אם תחממו את המים, הם ירתחו. הבדיקה הכי מהירה היא להחליף את if ב-when: אם המשמעות אינה משתנה, לפניכם חוק קבוע, ואם היא נשמעת פתאום כמו הבטחה למועד מסוים, לפניכם תחזית.

### מתי כותבים פסיק במשפט תנאי?

רק כשפסוקית ה-if פותחת את המשפט: If the gate is locked, ring the bell. אם השער נעול, צלצלו בפעמון. כשפסוקית התוצאה פותחת, לא כותבים פסיק: Ring the bell if the gate is locked. אותה משמעות בדיוק. הפסיק אינו חלק מהדקדוק של התנאי ואינו משנה דבר במשמעות, אלא עוזר לקורא: הוא מסמן איפה נגמר התנאי ומתחילה התוצאה. כשהתוצאה באה ראשונה, המילה if עצמה כבר עושה את העבודה הזו, ולכן הפסיק מיותר.

מה משפט תנאי מוסר לקורא?

The rule in English

A conditional sentence has an if-clause and a result clause. In the zero conditional both clauses use the present simple, because the result is always true. In the first conditional the if-clause uses the present simple and the result clause uses will, because the situation is a real future possibility. English never puts will inside the if-clause.

## paragraph

בעברית פסוקית התנאי נאמרת בעתיד: ״אם ירד גשם מחר, נעביר את המשחק פנימה.״ המילה ״ירד״ מציינת עתיד, ונשמעת לנו הכרחית. באנגלית זה בדיוק מה שאסור: אחרי if בא הווה פשוט, גם כשהמשמעות היא עתיד. זו הטעות השכיחה ביותר של דוברי עברית בנושא הזה, ולכן היא מקבלת כאן חלק משלה. שני הדגמים שבעמוד נלמדים בכיתה ט ברמת זיהוי: המטרה היא לקרוא משפט תנאי בתוך טקסט, להבין מה הוא מוסר, לבחור בין משפטים נתונים ולהסביר מדוע משפט מסוים שגוי.

תוצאה שחוזרת בכל פעם

הדגם הראשון מוסר עובדה קבועה: בכל פעם שהתנאי מתקיים, התוצאה מתקיימת. שתי הפסוקיות בהווה פשוט, ואין בהן will כלל.

If you press this button, the machine stops. אם לוחצים על הכפתור הזה, המכונה נעצרת. If plants do not get light, they lose their colour. אם צמחים אינם מקבלים אור, הם מאבדים את צבעם. בשני המשפטים אין דיבור על מקרה אחד ואין תחזית. מדובר בכלל שנכון בכל פעם מחדש.

סימן זיהוי שימושי: בדגם הזה if ו-when מוסרים את אותו דבר. When you press this button, the machine stops. זהה במשמעות. אם ההחלפה אינה משנה דבר, לפניכם תנאי של עובדה קבועה.

המבנה של zero conditional

שימו לב שאין will באף אחת משתי הפסוקיות. התוצאה כאן אינה תחזית אלא עובדה, ולכן ההווה הפשוט מספיק בשני החלקים.

## section

המבנה של first conditional

פסוקית התנאי בהווה פשוט, פסוקית התוצאה עם will. הקיצורים נפוצים מאוד בדיבור ובכתיבה קלילה: If the bus is late, we'll wait at the kiosk. ובשלילה won't.

למה אין will אחרי if

זו הנקודה היחידה בנושא הזה שבאמת מפילה דוברי עברית, ולכן כדאי לעצור עליה. המשמעות של פסוקית התנאי היא עתיד, אבל הצורה שלה היא הווה.

לא If it will rain tomorrow, we will move the game indoors. אלא If it rains tomorrow, we will move the game indoors. אם ירד גשם מחר, נעביר את המשחק פנימה. העברית מחייבת כאן צורת עתיד, ולכן התרגום המילולי נשמע נכון ואפילו טבעי. באנגלית פסוקית שנפתחת ב-if מקבלת הווה פשוט, וה-will היחיד במשפט יושב בפסוקית התוצאה. העתיד מסומן פעם אחת, ולא פעמיים.

אותו כלל חל גם על פסוקיות זמן שנפתחות ב-when, before ו-after: When the film ends, we will call you. כשהסרט ייגמר, נתקשר אליכם. בדיקה מהירה בקריאה: will מיד אחרי if הוא כמעט תמיד סימן לטעות.

מה עוד יכול לעמוד בפסוקית התוצאה

תוצאה עם מודאל

If you miss the bus, you can take the next one. אם תפספסו את האוטובוס, אפשר לנסוע באוטובוס הבא. המילה can מוסרת אפשרות ולא הבטחה.

If you see Noa, tell her to call me. אם תפגשו את נועה, תגידו לה שתתקשר אליי. פסוקית התוצאה היא הוראה, ולכן הפועל בצורת הבסיס.

הצעה מרוככת: if you like

If you like, I can explain it again. אם תרצו, אני יכול להסביר שוב. כאן התנאי אינו באמת תנאי, אלא דרך מנומסת להציע משהו.

בשלוש הצורות פסוקית ה-if נשארת בהווה פשוט. מה שמשתנה הוא רק מה שעומד בפסוקית התוצאה.

Yael: If you press this switch, the projector turns on. יעל: אם לוחצים על המתג הזה, המקרן נדלק. תנאי של עובדה קבועה, ולכן שתי הפסוקיות בהווה פשוט. Nadav: And if it does not turn on? נדב: ואם הוא לא נדלק? שאלה שמשאירה את התוצאה פתוחה, ולכן אין בה will. Yael: If it does not turn on, we will use the small screen. יעל: אם הוא לא יידלק, נשתמש במסך הקטן. אפשרות ממשית אחת בעתיד, ולכן will בפסוקית התוצאה בלבד. Nadav: We will start at four unless the bus is late. נדב: נתחיל בארבע, אלא אם האוטובוס יאחר. המילה unless כאן פירושה ״אלא אם״, וכדאי פשוט לזהות אותה בקריאה. Yael: If you like, I can bring the cable from home. יעל: אם תרצה, אני יכולה להביא את הכבל מהבית. הצעה מנומסת, ולא תנאי אמיתי.

## טעויות נפוצות, מוסברות

will אחרי if

לא If it will rain tomorrow, the trip will be shorter. אלא If it rains tomorrow, the trip will be shorter. אם ירד גשם מחר, הטיול יתקצר. פסוקית ה-if נשארת בהווה פשוט גם כשהמשמעות עתידית.

will שנעלם מהתוצאה

לא If the bus is late, we wait at the kiosk. כשמדובר במקרה של מחר, אלא If the bus is late, we will wait at the kiosk. אם האוטובוס יאחר, נחכה בקיוסק. בלי will המשפט נקרא כנוהג קבוע ולא כתוכנית למקרה אחד.

פסיק מיותר

לא Ring the bell, if the gate is locked. אלא Ring the bell if the gate is locked. צלצלו בפעמון אם השער נעול. פסיק נדרש רק כשפסוקית ה-if פותחת את המשפט.

הווה מתמשך אחרי if

לא If it is raining tomorrow, we will move the game indoors. כשמתכוונים לתחזית פשוטה, אלא If it rains tomorrow, we will move the game indoors. אם ירד גשם מחר, נעביר את המשחק פנימה. בדגם הזה פסוקית התנאי בהווה פשוט.

## סיכום לחזרה

שני דגמים בלבד. zero conditional: הווה פשוט בשתי הפסוקיות, מוסר משהו שנכון תמיד, ולכן אפשר להחליף בו if ב-when בלי לשנות את המשמעות. first conditional: הווה פשוט אחרי if ותוצאה עם will, מוסר אפשרות ממשית אחת בעתיד. בשום מקרה לא will אחרי if. פסיק רק כשהתנאי פותח את המשפט. במקום will יכולים לעמוד מודאל או ציווי, ו-if you like משמש לריכוך הצעה.
