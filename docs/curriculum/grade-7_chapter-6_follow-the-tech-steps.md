## שאלות ותשובות

### מהו Imperatives begin with the action?

An imperative often uses the base form of a verb without a written subject. It tells the reader what action an instruction names. Open the app. Select New Note. Type a title. Save the note. The understood subject is the person following the guide. Opens the app is not the same imperative form: opens normally belongs to a statement about he, she, or it. A command can be short while still naming its object. 'Select New Note' is more precise than 'Select something'.

### מהו Separate steps keep commands readable?

Several imperative sentences can form an ordered procedure. Each sentence can keep one main action in focus. Open the menu. Select the file. Read the file name. First, next, and finally can also mark positions in a supplied sequence. They describe order rather than the name of a button. A paragraph full of repeated it can become unclear when several files or screens are mentioned. Repeating the relevant noun can improve the guide.

### In the Maple Notes guide, what shows that the save step has finished?

In the fictional Maple Notes guide, a small 'Saved' message beside the title confirms that saving has finished. It is a visible result of the save step, distinct from the earlier blank note and the later return to the note list.

## About this topic

A technical instruction connects an action with an object: open a menu, select a file, or close a window. The order matters because a later step may depend on an earlier one. Clear instructions name the object precisely enough for a reader to understand which screen, button, or file is involved.

עזרה בעברית

הוראה ברורה מחברת בין פעולה לפריט מסוים. קראו גם את סדר השלבים, כי לפעמים אי אפשר לבצע פעולה לפני שהשלב הקודם הושלם.

## Words for devices and instructions

Digital technology includes tools such as computers and the software they use. A device is a piece of equipment, such as a tablet. A screen displays information. A keyboard has keys for entering text. A menu lists available choices. A file stores a piece of digital information. To select is to choose an item; to save a file is to keep its current contents for later use.

עזרה בעברית

למדו את שמות החלקים במחשב לצד הפעולות שעושים בהם. שימו לב שהמילה save פירושה כאן לשמור מידע לשימוש בהמשך.

## A complete example guide

Original guide for an invented app, Maple Notes. The controls belong only to this example.

1. Open Maple Notes. The home screen shows your note list. 2. Select New Note. A blank note appears. 3. Type a title in the Title box. The title names the note in the list. 4. Write the note in the large text box below the title. 5. Select Save. A small Saved message appears beside the title. 6. Select Back to List. The new title appears in the note list.

The guide describes a procedure in order. It does not claim that every note app uses the same buttons or saves in the same way.

זהו מדריך ליישומון דמיוני, ושמות הכפתורים שייכים לדוגמה הזאת. בכל שלב הפרידו בין הפעולה שהתבקשתם לבצע לבין התוצאה שמתוארת אחריה.

מספרי השלבים מראים מה צריך לקרות קודם. לפני כל פעולה, בדקו איזה פריט או מידע מהשלב הקודם נדרש כדי שהיא תהיה אפשרית.

Steps depend on earlier steps

A procedure is a series of actions leading to a result. Numbered steps show their order visually.

The blank note must exist before text can be entered into it. The title and body must be present before the described Save action stores them. Back to List returns to the list after saving.

The order is part of the guide's meaning. Alphabetising the command verbs would make an attractive list but destroy the procedure.

## Names and references

The guide first introduces a blank note. Later, the note refers to that same item. New Note and Back to List are button labels in this example. Their capitals distinguish those displayed names from ordinary words in the explanation.

עזרה בעברית

הביטוי a blank note מציג פתק לראשונה, ואחר כך the note מתייחס לאותו פתק מוכר. אותיות גדולות בשמות הכפתורים עוזרות לזהות את התווית שצריך לחפש במסך.

## A precise instruction and an unclear one

Precise

Select Save beside the title. The command names the displayed control and gives a location.

Unclear

Press that one. Without a visible shared reference, that one does not identify a control.

A short instruction is useful only when its key object is clear.

עזרה בעברית

הוראה קצרה מועילה רק אם ברור על מה ללחוץ. שם הכפתור והמיקום שלו מספקים מידע מדויק יותר ממילים כמו ״ההוא״ או ״זה״.

## A result is not the same as a command

'Select Save' names an action. 'A Saved message appears' describes the expected result in the invented app. Both help explain the procedure, but they have different sentence functions. A guide that names a result gives the reader a concrete way to understand what the preceding action changes.

עזרה בעברית

ציווי אומר מה לעשות; משפט תוצאה מתאר מה משתנה בעקבות הפעולה. שימו לב להבדל בין פועל כמו select לבין appears, שמתאר משהו שמופיע.
